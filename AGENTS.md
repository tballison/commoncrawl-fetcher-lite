# Agent guidance for commoncrawl-fetcher-lite

Detailed guidance lives in `.skills/`: `dev/` for working on this code, `user/` for using it to fetch
from Common Crawl. One directory per skill, each with a `SKILL.md`.

| Skill | Use when |
|-------|----------|
| `.skills/dev/development/SKILL.md` | Building, testing or changing the code |
| `.skills/user/fetching/SKILL.md` | Running fetches: commands, config, MIME types, monitoring |
| `.skills/user/columnar-query/SKILL.md` | Any QueryIndex/CountIndex run -- read first; bandwidth rules |
